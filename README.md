# ZAVYRON WEB V4 — Permissões administrativas (DEMO)

Abra `index.html`. Selecione Admin A ou Admin B para editar seu próprio servidor demonstrativo. Selecione Membro sem Administrador para visualizar o Servidor A em modo somente leitura. O Servidor B não aparece para esse membro.

**Aviso de segurança:** este protótipo roda inteiramente no navegador, sem login Discord, backend ou controle de acesso seguro. A checagem JavaScript pode ser contornada. Não publique como painel de administração real, não insira credenciais e não conecte ao bot sem implementar OAuth2 e validação de autorização no backend para cada operação, com checagem de guild_id, presença do bot e permissão ADMINISTRATOR no Discord.

A versão do bot V14.4 não foi modificada.
